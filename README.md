# homebrew-aspenx

Homebrew tap for [AspenX](https://aspenx.dev): parallel feature workspaces for a Docker Compose monorepo.

```sh
brew install aspenxdotdev/aspenx/aspenx
```

The formula downloads the release tarball from `https://aspenx.dev/releases/<version>/` and checks its SHA-256. It is rendered by the AspenX release script; edit it there, not here. Docs: https://aspenx.dev/docs/install/
